Vežba 14 - Veb dizajn

Uputstvo:
1. Napraviti GitHub repozitorijum, npr. vezba14-sajt.
2. Otpremiti fajlove index.html i style.css.
3. U Settings > Pages izabrati Deploy from a branch, branch main i folder /root.
4. Kada sajt bude objavljen, kopirati URL u Word izveštaj.
5. Testirati URL preko PageSpeed Insights, W3C Validator ili GTmetrix i ubaciti screenshot-ove u izveštaj.
